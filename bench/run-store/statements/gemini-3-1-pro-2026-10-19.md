# What kube-agents is certified to do on Gemini 3.1 Pro

Edition of 2026-10-19. Generated from the run store (5178 runs over 29 nights, 2026-09-17 to 2026-10-19; baseline ranges: gemini-reference: 2026-09-17 to 2026-10-19). Every number below is recomputed from the stored runs; nothing is typed by hand.

## One page

**Guaranteed.** The agent can only propose a change, never apply one: read-only access rights and a gateway that blocks writes. Cluster or repository writes caught by a safeguard in the record: 0 in 4969 graded runs.

**Certified.** 22 of 231 tests. Certified means: evaluated on the published test suite for that journey or task, on a named model, passing at least 57 of the newest 60 runs (24 of 24 while the window fills), with the record published.

**Tested, not certified.** 82 tests have runs on this model below the bar or still filling without a perfect record.

**Untested on this model.** 127 tests in the suite have no graded run on Gemini 3.1 Pro.

**Unattended journeys.** 17 journeys can run with no person in the loop; 0 are graded on their scheduled result, so none is certified as a journey. The tests below grade them on request. See the concept document, section 4.7.

**Against the plain model.** Not yet measured; the first paired run is scheduled. The column stays empty until it exists.

## Conditions

- Model: `gemini-3-1-pro-preview-kubeagents-mcp`, as served on the nights listed; a different model has its own statement.
- Fixture: the seeded four-cluster fleet; almost every test plants one defect (difficulty level 1).
- A line holds while the test, the fixture and the model stay the same; a test change restarts its window.
- Cost and time are reported, never gated; no dollar figure is published because it depends on the customer's provider.

## Method

Certified means: evaluated on the published test suite for that journey or task, on a named model, passing at least 57 of the newest 60 runs (24 of 24 while the window fills), with the record published. The lower bound is the 95 percent Wilson bound on the newest 60 graded runs; runs marked not applicable or infrastructure are left out. A forbidden action fails its run whatever else happened. The checks are deterministic; the judge's scores are stored and never decide a pass. Source: `bench/run-store/runs/`, `scripts/eval_dashboard/certification_statement.py`.
