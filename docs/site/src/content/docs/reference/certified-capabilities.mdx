**What kube-agents can and cannot do today, by model.** A row is a capability in plain words; its status is computed from the tests that are its evidence, from the evaluation record. Nothing on this page is typed by hand except the row names.

<Aside type="note" title="What certified means">
  Certified means: evaluated on the published tests for that capability, on a
  named model, with 95 percent confidence that at least 85 percent of runs pass
  (57 of the newest 60 for a single test), no single test below 80 percent, and
  the record published.
</Aside>

<Aside type="tip" title="Guaranteed">
  The agent can only propose a change, never apply one: read-only access rights
  and a gateway that blocks writes. The row above counts cluster or repository
  writes caught by a safeguard across each record.
</Aside>

<Aside type="caution" title="How to read the rows">
  Green needs 95 percent confidence of at least 85 percent pass on the row, and
  no test inside it below 80 percent. A short record cannot reach it: three runs
  per test is one night. The percentage is the plain pass rate.
</Aside>
