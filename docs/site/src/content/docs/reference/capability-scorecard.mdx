**What kube-agents can and cannot do today, by model.** A row is a capability in plain words; its status is computed from the tests that are its evidence, from the evaluation record. The first tab compares the models side by side; the others are one page per model. Nothing on this page is typed by hand except the row names.

<Aside type="note" title="The bar">Certified means: evaluated on the published test suite for that journey or task, on a named model, passing at least 57 of the newest 60 runs (24 of 24 while the window fills), with the record published.</Aside>
