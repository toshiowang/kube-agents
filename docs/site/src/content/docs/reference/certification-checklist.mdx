One page per model, regenerated from the evaluation record. A row is a capability in plain words; its status is computed from the tests that are its evidence. Nothing on this page is typed by hand except the row names.

<Aside type="note" title="The bar">Certified means: evaluated on the published test suite for that journey or task, on a named model, passing at least 57 of the newest 60 runs (24 of 24 while the window fills), with the record published.</Aside>

## Not on this page

Twenty documented promises with no test (see the journey inventory in the design documents); the dollar cost of a run; any comparison against a plain model, which the first paired run adds as a column.

## Method

Rows: `bench/run-store/capabilities.yaml`. Numbers: `bench/run-store/runs/`, the newest 60 graded runs per test on the model; runs marked not applicable are left out; the lower bound is the 95 percent Wilson bound. Generators: `scripts/eval_dashboard/capability_checklist.py` and `render_checklist.py --mdx`.
